# Favourite Student List

A React application built using React Router and Context API.

## Features

- Student List Page
- Favourite Students Page
- Add students to favourites
- Prevent duplicate favourites
- Remove students from favourites
- Empty state message
- Responsive design

## Technologies Used

- React
- JavaScript
- React Router
- Context API
- CSS
- Vite

## Run Locally

npm install

npm run dev
